# ScreenMind (bundled tree)

> Optional **desktop** screen-memory engine integrated with AquaScope screen memory.

## Role for iQOO hackathon

- Phone side: screen memory OCR → episodic memory / Ask  
- This folder: PC-side ScreenMind (Gemma / llama.cpp) for deeper screen RAG when judges want the full stack  

**Primary hackathon demo does not require this folder** — on-device Ask + AquaScope sensing stand alone on iQOO 15.
